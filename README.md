# Piatscheck & Söhne

Satire-Website eines Familienbetriebs – statische Seite ohne Build-Schritt.

## Struktur

- `index.html` – Inhalt
- `style.css` – Styles
- `script.js` – Terminrechner
- `assets/` – Bilder

## Lokal ansehen

`index.html` im Browser öffnen.

## Veröffentlichen mit GitHub Pages

1. Repository auf GitHub anlegen und alle Dateien hochladen
2. Settings → Pages → Source: *Deploy from a branch*
3. Branch `main`, Ordner `/ (root)` → Save
4. Die Seite ist nach ca. 1 Minute unter `https://<benutzername>.github.io/<repo-name>/` erreichbar
